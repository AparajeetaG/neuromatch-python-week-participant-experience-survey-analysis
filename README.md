# Participant Experience & Program Evaluation for Neuromatch Python Week

This repository contains a **participant experience and program evaluation analysis** for **Neuromatch Python Week**, designed to understand learner readiness, perceived progress, support needs, and improvement priorities through a combination of **pre/post cross-sectional and longitudinal survey analysis**, **qualitative thematic coding**, **descriptive statistics**, and **interactive visualization**.

The project focuses on turning participant experience into decision-ready evidence. Structured survey responses and open-ended feedback were analyzed together to identify who the program reached, what participants needed most, how they experienced the training, and which changes would be most actionable for future iterations. A core strength of this work is the **qualitative-to-quantitative transformation** of open-ended survey feedback into coded themes, measurable categories, and interactive visual summaries that support program planning and stakeholder discussion.

---

## Project Overview

Neuromatch Python Week was developed as a learner-support initiative to help prospective participants strengthen foundational Python skills and feel more prepared for Neuromatch training programs. This repository evaluates that experience using survey data and related program materials in order to answer questions such as:

- Who did the program reach?
- What level of readiness did participants have at entry?
- What goals did participants bring into the program?
- How did participants describe their experience after the training?
- What kinds of support or design changes appear most needed for the next iteration?
- How can qualitative participant feedback be translated into clear quantitative evidence for planning and decision-making?

This repository is therefore both an **analysis project** and a **program evaluation artifact**, with outputs designed for interpretation by technical and non-technical stakeholders alike.

---

## Objective

The objective of this project is to evaluate **participant experience, learning-related self-report patterns, and future support needs** in Neuromatch Python Week through a structured survey-based workflow. The analysis is intended to help transform raw participant feedback into evidence that can inform:

- future training design
- learner support strategy
- program communication
- stakeholder reporting
- next-year planning and prioritization

---

## Data Description

The primary dataset for this project is an Excel workbook containing **Neuromatch Python Week pre- and post-program survey responses**, organized into separate sheets for the **Pledge / Pre Week Survey** and the **Post Week Survey**. Together, these sheets capture participant background, self-reported Python ability, learning goals, course interests, future application intent, support preferences, and post-program reflections. The dataset therefore combines **structured survey fields** such as country, ability level, intended course track, and follow-up interest with participant-centered program evaluation indicators such as whether the week met their goal and whether they would join again next year. Because the pre and post surveys follow a related structure, the workbook supports a **pre/post program evaluation framework** for understanding readiness, expectations, engagement, and perceived learning outcomes across the training experience.

A particularly important feature of this dataset is that it includes both **quantitative response fields** and **open-ended qualitative feedback**, making it suitable for a richer participant experience analysis than standard survey tabulation alone. In addition to descriptive survey variables, the workbook contains free-text responses on participant needs, reflections, and suggestions, which can be systematically coded into themes and transformed into measurable categories. This allows the project to move from raw participant voice to **structured quantitative evidence**, using thematic coding, descriptive statistics, and visualization to identify major patterns in learner needs, perceived gains, and program improvement priorities. In that sense, the data is best described as a **pre/post cross-sectional survey dataset with qualitative response components**, designed for participant experience analysis, training evaluation, and decision-oriented program improvement.

## Methodological Approach

This project uses a **pre/post cross-sectional and longitudinal survey analysis framework** with qualitative-to-quantitative integration.

### Core methods used
- **Pre/post cross-sectional survey analysis**
- **Longitudinal repeated-measure analysis** where linked responses or before/after comparisons were available
- **Qualitative thematic coding** of open-ended survey feedback
- **Qualitative-to-quantitative transformation** of coded themes into measurable categories
- **Descriptive statistics**
- **Decision-oriented visualization**
- **Interactive HTML reporting**

### Analytical logic
The workflow began with structured survey review and variable summarization. Open-ended responses were then reviewed and coded into thematic categories that reflected participant needs, sentiments, barriers, and improvement suggestions. These coded categories were aggregated into counts, proportions, and planning-relevant evidence summaries. The final stage focused on visual communication, using both static and interactive outputs to make the findings easier to interpret in a stakeholder setting.

This approach is especially useful for program evaluation contexts where participant experience cannot be understood through numeric survey items alone. The analysis prioritizes not just statistical description, but the translation of learner voice into evidence that is measurable, interpretable, and actionable.

## Data Ethics and Privacy Note

This project is intended only for program evaluation, participant experience analysis, and training-improvement purposes. The public-facing report is designed to present aggregated findings, coded themes, descriptive statistics, and interactive visualizations without requiring access to the raw participant-level survey data.

Raw survey responses may contain personally identifiable information, free-text comments, or internal program context, so they should not be shared publicly unless they have been reviewed, de-identified, and approved for release. Any interpretation of the results should also account for survey coverage, response imbalance between pre- and post-survey data, and the fact that open-ended qualitative feedback involves structured but interpretive thematic coding.

The goal of this repository is to make the analysis transparent and useful while respecting participant privacy and responsible data-sharing practices.
